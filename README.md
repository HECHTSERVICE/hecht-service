# Hecht Service — Warranty Management System

Система реєстрації та управління гарантіями техніки Hecht.

## Stack
- **Frontend:** Next.js 15 (App Router)
- **Database:** Supabase (PostgreSQL)
- **Hosting:** Vercel
- **Design:** Space Grotesk + Inter, light/dark theme

## Features
- Публічна форма реєстрації гарантії
- Адмін-панель з дашбордом
- Панель сервісного центру
- Чат-коментарі між адміном та сервісом
- 2FA авторизація
- Експорт в Excel
- PDF-сертифікат з QR-кодом
